# 숨 (Soom) — iPhone 호흡 앱

구슬이 커지면 들이마시고, 작아지면 내쉬는 호흡 앱입니다. SwiftUI로 만들었고, 4초·5초·6초·7초·8초 같은 리듬을 한 번에 고르거나 들숨·멈춤·날숨·멈춤을 0.5초 단위로 직접 정할 수 있습니다.

## 실행하기

1. Mac에서 **Xcode 16 이상**(권장: Xcode 26)으로 `breathing-ios/Soom.xcodeproj`를 엽니다.
2. 왼쪽에서 `Soom` 프로젝트 → `Soom` 타깃 → **Signing & Capabilities**에서 **Team**을 내 Apple 계정으로 고릅니다.
3. 번들 ID(`com.soom.breathing`)가 이미 쓰이고 있다는 오류가 나면 `com.내이름.soom`처럼 바꿉니다.
4. iPhone을 연결하거나 시뮬레이터를 고르고 ▶︎(⌘R)를 누릅니다.

- 최소 iOS 17. iOS 26에서는 카드와 버튼에 Liquid Glass가 적용됩니다.
- 진동(햅틱)은 시뮬레이터에서 느낄 수 없으니 실제 iPhone에서 확인하세요.
- 무료 개인 계정에서 HealthKit 서명 오류가 나면 Signing & Capabilities에서 **HealthKit**을 지우세요. 앱은 그대로 동작하고 설정의 ‘건강 앱에 기록’만 쓸 수 없습니다.

## 기능

| 영역 | 내용 |
|---|---|
| 빠른 리듬 | 홈에서 **4·5·6·7·8초** 칩을 누르면 같은 초로 들이마시고 내쉬는 균등 호흡이 바로 설정됩니다 |
| 내 패턴 만들기 | 들숨 / 들숨 후 멈춤 / 날숨 / 날숨 후 멈춤을 각각 0.5초 단위로 설정(멈춤 0초 = 건너뜀). −/+ 버튼, 빠른 칩(3~8초), 자주 쓰는 리듬(4·7·8, 박스, 7·11 등)으로 채우기. 실시간 미리보기 구슬 |
| 기본 호흡법 9가지 | 목적(균형·진정·수면·집중·활력)별로 정리. 각 호흡법마다 설명, 효과, 하는 방법, 주의, 출처 |
| 세션 길이 | 시간(1~20분) · 횟수(4~30회) · 자유(원할 때 종료). 예상 횟수/시간 표시, 4-7-8은 권장 4회 안내 |
| 세션 화면 | 숨결에 맞춰 커지고 작아지는 구슬, 단계별 남은 초, 단계 진행 링, 리듬 표시(현재 단계 강조), 전체 진행 바·남은 시간 |
| 안내 | 신호음(합성 싱잉볼 소리), 한국어 음성 안내(끄기/처음 3회만/항상), 진동(단계 전환 시 / 들숨에 강해지고 날숨에 약해지는 연속 진동) |
| 배경 소리 | 빗소리 · 파도 · 깊은 소음 · 백색 소음 (앱 안에서 실시간 합성, 음량 조절) |
| 편의 | 시작 전 3초 준비(탭하면 건너뜀), 구슬을 탭해 일시정지/재개, 세션 중 화면 켜두기, 세션 중에도 소리·진동 바로 변경, 잠금 화면에서도 소리 안내 계속, 전화가 오면 자동 일시정지 |
| 기록 | 세션 후 기분 기록(😣~😌), 연속 실천 일수·최장 기록, 최근 7일 그래프, 전체 시간·횟수, 가장 많이 한 호흡, 길게 눌러 삭제 |
| 연동 | Apple 건강 앱 ‘마음챙김 시간’ 저장, 매일 알림 |
| 꾸미기 | 테마 5가지(새벽·바다·숲·노을·한밤), 어두운 화면 기반의 은은한 그라데이션 |
| 접근성 | VoiceOver 라벨과 단계 안내, 동작 줄이기 설정 시 크기 대신 밝기로 표현, Dynamic Type |
| 안전 | 첫 실행 안내, ‘안전하게 호흡하기’(어지러움, 운전·수영 금지, 질환별 주의) |

## 호흡법 조사 요약

| 호흡법 | 리듬(초) | 목적 | 근거 |
|---|---|---|---|
| 균등 호흡 | 4 · 4 (4~8초 조절) | 입문, 균형 | 요가 사마 브리티 |
| 공명 호흡 | 5.5 · 5.5 | 심박변이도(HRV), 자율신경 균형 | 분당 5~6회 느린 호흡 연구 (Lehrer & Gevirtz 2014, Zaccaro 외 2018) |
| 주기적 한숨 | 2.5(들숨) · 1(한 번 더) · 6(날숨) | 가장 빠른 진정, 기분 개선 | Balban 외 2023, *Cell Reports Medicine* — 하루 5분 |
| 이완 호흡 | 4 · 6 | 스트레스 완화 | 긴 날숨 → 부교감신경 활성 |
| 박스 호흡 | 4 · 4 · 4 · 4 | 집중, 긴장 완화 | 미 해군 특수부대 훈련으로 알려짐 |
| 삼각 호흡 | 4 · 4 · 4 | 가벼운 집중 | 박스 호흡 변형 |
| 4-7-8 호흡 | 4 · 7 · 8 | 수면, 불안 | Andrew Weil 박사 — 처음 4회 권장 |
| 깊은 이완 | 4 · 8 | 수면 (숨 참기 없이) | 1:2 호흡 |
| 활력 호흡 | 4 · 2 | 졸음 깨기 | 긴 들숨 → 각성 |

인기 호흡 앱들이 공통으로 갖춘 기능(시각 가이드, 소리·음성·진동 안내, 프리셋+사용자 설정, 세션 길이, 기록과 연속 일수, 리마인더, 건강 앱 연동, 배경 소리, 안전 안내)을 모두 넣었습니다.

## 구조

```
breathing-ios/
├── Soom.xcodeproj          Xcode 프로젝트 (폴더 동기화 방식이라 파일을 추가하면 자동 포함)
├── Config/                 Info.plist(백그라운드 오디오), entitlements(HealthKit)
├── Soom/
│   ├── SoomApp.swift       앱 진입점, 탭, 화면 전환
│   ├── Core/               순수 로직 (UI 없음, 테스트 대상)
│   │   ├── BreathPhase.swift, BreathingPattern.swift   단계·패턴·세션 길이
│   │   ├── Presets.swift                                기본 호흡법 9가지와 설명
│   │   ├── SessionTimeline.swift                        경과 시간 → 현재 단계·구슬 크기 계산
│   │   ├── SessionRecord.swift                          기록과 통계(연속 일수, 주간 합계)
│   │   └── Preferences.swift                            사용자 설정
│   ├── Engine/             세션 진행(BreathingSessionController), 소리 합성(AudioCueEngine), 진동(HapticsEngine)
│   ├── Store/              JSON 저장소, HealthKit, 알림
│   ├── UI/                 Home(홈·상세·편집·온보딩), Session(세션·완료), History, Settings, Components(테마·구슬·버튼)
│   └── Assets.xcassets     앱 아이콘, 강조색
├── Package.swift           Core만 따로 빌드해 테스트하는 패키지
└── Tests/SoomCoreTests/    타임라인·패턴·통계 테스트 20개
```

시간은 `Date` 기준으로 계산합니다. `SessionTimeline.snapshot(at:)`이 경과 시간을 받아 현재 단계, 남은 초, 구슬 크기(사인 곡선으로 보간)를 돌려주는 순수 함수라서, 화면이 잠시 늦게 그려져도 리듬이 밀리지 않습니다.
