# 01. 서비스 기획 — Mappin

> "내가 저장한 장소와 그곳에 쌓인 기록을 지도 위에서 다시 보는 서비스"

## 1. 목표와 범위

| 구분 | 내용 |
|---|---|
| 핵심 가치 | 장소(POI)를 저장하고, 시간이 흐르며 쌓이는 메모·태그·아이콘 같은 맥락까지 함께 기억해 지도 위에 다시 보여준다 |
| 1차 플랫폼 | 웹 (반응형, 모바일 브라우저 포함) |
| 2차 플랫폼 | iOS, Android (같은 API·같은 도메인 모델 사용) |
| 1차 지역 | 대한민국 (해외는 대체 지도 공급자로 기본 지원) |
| 범위 밖 (MVP) | 길찾기/내비게이션, 리뷰 커뮤니티, 실시간 위치 공유 |

## 2. 사용자 시나리오

1. **저장** — 지도에서 길게 누르거나, 장소를 검색하거나, "현재 위치"로 핀을 꽂는다 → 이름·아이콘·카테고리·태그·첫 메모를 입력하고 저장한다.
2. **기록 누적** — 같은 장소를 다시 방문해 "2026-11 재방문: 웨이팅 30분" 같은 메모를 덧붙인다. 이전 메모는 사라지지 않고 타임라인으로 남는다.
3. **다시 보기** — 지도에서 카테고리별·태그별로 필터링한다. 많이 모인 곳은 클러스터로 묶이고, 핀은 각자 고른 아이콘과 색으로 표시된다.
4. **정리** — 카테고리를 "맛집 > 서울 > 성수"처럼 계층으로 만들고, 장소를 옮기거나 일괄로 태그를 붙인다.
5. **공유** — "성수 맛집" 카테고리를 친구에게 보기 권한으로 공유하거나, 링크로 공유한다. 받은 사람은 자기 지도 위에 공유받은 레이어를 겹쳐 본다.
6. **이동/백업** — 내 데이터를 GeoJSON, CSV, GPX로 내보내거나, 다른 서비스에서 가져온다.

## 3. 기능 목록 (우선순위)

### P0 — MVP (웹)
- **계정**: 이메일 가입·로그인, 소셜 로그인(Google, Kakao, Apple은 iOS 출시 전에 필수), 로그아웃, 비밀번호 재설정, 회원 탈퇴
- **지도 표시**: 기본 지도, 내 위치, 확대/축소, 지도 범위(bbox) 기반 내 장소 로딩, 클러스터링
- **장소(POI) CRUD**: 지도 클릭·검색·현재 위치로 생성, 수정, 삭제(휴지통 30일), 복원
- **부가 정보**
  - 위치값: 위도·경도(WGS84), 정확도(m), (선택) 고도
  - 주소: 도로명·지번 (역지오코딩으로 자동 채움)
  - 저장 시간·수정 시간·(선택) 방문 시간
  - 아이콘: 시스템 아이콘 세트 + 색상 선택
  - 카테고리: 장소마다 1개, 계층형
  - 태그: 여러 개, **태그를 붙인 시각과 붙인 사람** 기록
  - 메모: 타임라인 형태로 여러 개, 각 메모의 **수정 이력(리비전)** 보존
  - 변경 이력: 장소의 모든 변경(이름, 아이콘, 카테고리, 태그 추가·제거, 위치 이동)을 이벤트로 기록
- **필터·목록**: 카테고리 트리, 태그 칩, 키워드 검색, 목록 보기와 지도 보기 전환
- **공유(기본)**: 장소·카테고리 단위 공유, 링크 공유(읽기 전용), 권한 회수

### P1 — 모바일 출시와 함께
- iOS/Android 앱 (오프라인 캐시와 동기화)
- 친구(지인) 관계: 요청, 수락, 친구 목록에서 바로 공유
- 공유 권한 `editor`: 공유받은 카테고리에 함께 장소 추가 (공동 큐레이션)
- 사진 첨부 (메모에 이미지)
- 내보내기/가져오기 (GeoJSON, CSV, GPX, KML)

### P2 — 이후
- 커스텀 아이콘 업로드, 지도 스타일 테마
- 방문 기록 자동 제안 (위치 권한 필요, 법적 검토 후)
- 스마트 필터 ("최근 3개월 동안 메모를 남긴 곳", "태그가 없는 곳")
- 공개 큐레이션 페이지 (SEO)

## 4. 정보 구조 (도메인 모델 개요)

```
User ─┬─< Category (계층: parent_id)          카테고리 = 분류 + 기본 아이콘·색
      ├─< Tag                                   태그 = 자유로운 다중 라벨
      ├─< Place ──┬── Category (0..1)
      │           ├─< PlaceTag  (tagged_at, tagged_by)
      │           ├─< Note ───< NoteRevision    메모 타임라인 + 수정 이력
      │           ├─< PlaceEvent                모든 변경의 감사 로그(히스토리)
      │           └── ProviderRef (0..1)        외부 지도사 장소 ID (저장 허용 범위만)
      ├─< Share (target: place | category, 대상: user | link)
      └─< Friendship
```

### 카테고리와 태그를 둘 다 두는 이유
- **카테고리**: "이 장소는 무엇인가"를 한 가지로 정한다. 지도 핀의 기본 아이콘·색과 공유 단위가 된다. 계층형이라 "여행 > 제주"처럼 묶을 수 있다.
- **태그**: "이 장소에 대해 어떤 맥락이 있나"를 여러 개 단다. 예: `#데이트`, `#주차가능`, `#재방문의사`. 언제 붙였는지가 의미 있으므로 시각을 기록한다.
- 지도 필터는 `카테고리(하위 포함) AND 태그(OR/AND 선택)` 조합으로 동작한다.

### 아이콘 결정 우선순위
`장소에 직접 지정한 아이콘` > `카테고리 기본 아이콘` > `시스템 기본 핀`
(색상도 같은 규칙. 공유받은 레이어는 테두리나 배지로 구분한다.)

### 메모 히스토리 설계
- **Note** = 타임라인 항목. 시간 순서대로 계속 추가된다 ("시간적으로 추가한 메모").
- **NoteRevision** = 한 메모를 고칠 때마다 이전 내용을 보존한다 ("메모 내용 히스토리").
- **PlaceEvent** = 장소 자체의 변경 이벤트 (`place.created`, `place.moved`, `tag.added`, `icon.changed` 등). 화면에서는 메모와 이벤트를 합쳐 "이 장소의 타임라인"으로 보여준다.

## 5. 화면 구성 (웹 기준, 모바일도 같은 구조)

| 화면 | 주요 요소 |
|---|---|
| 지도 홈 | 전체 화면 지도, 상단 검색창, 좌측(모바일은 하단 시트) 카테고리/태그 필터, 클러스터·핀, 내 위치 버튼, `+` 버튼 |
| 장소 상세 (시트/패널) | 이름, 아이콘, 카테고리, 태그 칩, 주소, 저장 시각, 타임라인(메모 + 이벤트), 메모 입력창, 공유 버튼 |
| 장소 편집 | 위치 미세조정(핀 드래그), 아이콘·색 선택기, 카테고리 선택, 태그 입력(자동완성) |
| 카테고리 관리 | 트리 편집(드래그로 순서·부모 변경), 기본 아이콘·색, 공유 설정 |
| 공유함 | 내가 공유한 것 / 공유받은 것, 권한 변경·회수, 링크 복사 |
| 공유 링크 뷰 | 로그인 없이 보는 읽기 전용 지도 (OG 태그 포함 SSR) |
| 설정/계정 | 프로필, 연동 계정, 내보내기, 회원 탈퇴 |

## 6. 공유 모델

| 항목 | 정의 |
|---|---|
| 공유 대상(target) | `place` 하나 또는 `category` 하나 (하위 카테고리 포함 여부 옵션) |
| 받는 사람(grantee) | 가입한 사용자(친구 또는 이메일로 초대) 또는 **링크**(토큰을 가진 누구나) |
| 권한 | `viewer`(보기), `editor`(장소·메모 추가와 수정, P1) |
| 노출 범위 | 공유받은 사람에게는 장소의 이름·위치·아이콘·카테고리·태그·메모가 보인다. 비공개 메모(`is_private`)는 제외된다 |
| 수명 | 만료일(선택), 언제든 회수, 링크는 재발급 가능 |
| 받는 쪽 화면 | "공유받은 레이어"로 내 지도 위에 켜고 끌 수 있다. 원하면 "내 장소로 복사" (원본 출처 기록) |

## 7. 비기능 요구사항
- **데이터 독립성**: 사용자 데이터는 특정 지도사에 종속되지 않는다. 좌표는 WGS84로 저장하고, 지도사 장소 ID는 선택적인 참조값으로만 둔다 → 지도사를 바꿔도 데이터가 그대로 살아 있다.
- **오프라인 내성(모바일)**: 클라이언트가 만든 UUID와 변경 커서 기반 동기화로 오프라인에서도 작성할 수 있다.
- **성능**: 장소 1만 개 계정에서도 bbox 조회 p95 200ms 이하 (PostGIS GiST 인덱스, 클러스터링).
- **개인정보·위치정보**: 위치정보법·개인정보보호법 준수, 탈퇴 시 파기, 내보내기 제공 → [05-roadmap-and-compliance.md](05-roadmap-and-compliance.md)
